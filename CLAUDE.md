# awesome-agents

A production-grade Claude Code control centre: 16 engineering teams, 109 specialist agents,
each written to a top 0.1% professional standard.

## Delegate, do not improvise

Before doing domain work yourself, check whether an agent owns it.
Roster and `name` values: `.claude/teams/README.md`.

- **Architecture Team** (`.claude/teams/architecture.md`) — Own system-wide technical direction: boundaries, contracts, trade-offs, and long-term evolvability.
- **Backend Engineering Team** (`.claude/teams/backend.md`) — Build correct, observable, horizontally scalable services and the data layer beneath them.
- **Frontend Engineering Team** (`.claude/teams/frontend.md`) — Deliver fast, accessible, resilient user interfaces backed by a coherent design system.
- **Mobile Engineering Team** (`.claude/teams/mobile.md`) — Ship native-quality mobile experiences that survive poor networks, old devices, and store review.
- **Data & AI Engineering Team** (`.claude/teams/data-ai.md`) — Turn raw data into trustworthy products and ship AI systems that are evaluated, not vibed.
- **Platform Engineering Team** (`.claude/teams/platform.md`) — Provide paved roads that make the secure, reliable path the fastest path for product teams.
- **Quality Engineering Team** (`.claude/teams/quality.md`) — Prevent defects from reaching users through risk-based testing, automation, and fast feedback.
- **Security Engineering Team** (`.claude/teams/security.md`) — Make the system secure by default and prove it with threat models, tests, and controls evidence.
- **Release & Reliability Team** (`.claude/teams/release.md`) — Deliver change safely and keep production healthy against explicit SLOs and error budgets.
- **Product Strategy Team** (`.claude/teams/product.md`) — Decide what to build and why, with evidence, sequencing, and measurable outcomes.
- **Engineering Excellence Team** (`.claude/teams/excellence.md`) — Raise the floor of engineering practice through documentation, standards, and measurement.
- **IT Operations & Infrastructure Team** (`.claude/teams/itops.md`) — Run the corporate and production infrastructure that everything else stands on: servers, network, identity, endpoints, and recovery.
- **MLOps & Model Operations Team** (`.claude/teams/mlops.md`) — Take models and prompts from a notebook to reliable, monitored, reproducible production systems.
- **FinOps & Cost Engineering Team** (`.claude/teams/finops.md`) — Make technology spend visible, attributable, and efficient without slowing delivery down.
- **Enterprise Applications Team** (`.claude/teams/entapps.md`) — Deliver and integrate the internal systems the business runs on: ERP, CRM, workflow, and low-code platforms.
- **Governance, Risk & Privacy Team** (`.claude/teams/grc.md`) — Keep the organisation defensible: privacy by design, governed data, tracked risk, and audit evidence generated by systems.

Delegation chain: **architect decides, engineer implements, quality verifies, release ships.**
Do not skip a link.

## Generated files

`.claude/agents/*.md` and `.claude/teams/*.md` are generated. Edit `scripts/agents_data.py`
and run `python3 scripts/generate.py`. Hand edits to generated files are lost.

## Commands

`/team` route work · `/design` architecture pass + ADR · `/review` multi-lens diff review ·
`/ship` readiness gate · `/audit` security audit · `/incident` incident command ·
`/threat-model` STRIDE · `/cost` cost review · `/runbook` on-call runbook ·
`/agents` find the owner · `/onboard` explain this system.

## Output compression

Caveman is always on in this repository — see `AGENTS.md` for the rule other IDE agents load.
Prose is compressed; code, commands, file paths, and error strings are reproduced verbatim.
Drop it for security warnings, irreversible-action confirmations, and anything where a
fragment would be ambiguous, then resume. Commits, PRs, and documentation are written normally.

Install: `/plugin marketplace add juliusbrussee/caveman`, then `/caveman ultra`.

## Non-negotiable

Verified over asserted. Measured over estimated. Reversible over clever.
No secrets in code, logs, or prompts. No change without tests, observability, and a rollback path.
