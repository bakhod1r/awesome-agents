# Frontend Engineering Team

## Mission

Deliver fast, accessible, resilient user interfaces backed by a coherent design system.

## Charter

- Meet Core Web Vitals budgets on real devices, not lab averages.
- WCAG 2.2 AA is a build gate, not a follow-up ticket.
- One design system; no forked component variants.

## Roster (8)

- [Frontend Engineer](../agents/frontend-engineer.md) — Build accessible, performant interfaces that hold up on slow networks and real devices.
- [Product Designer](../agents/product-designer.md) — Design flows that solve the user problem with the least interface possible.
- [Web UX Quality Engineer](../agents/web-ux-quality-engineer.md) — Verify web experience quality: usability, responsiveness, performance, and polish.
- [Design System Engineer](../agents/design-system-engineer.md) — Build and maintain the component library so every surface stays consistent without forking.
- [Web Performance Engineer](../agents/web-performance-engineer.md) — Hold Core Web Vitals budgets on real user devices and networks, not lab averages.
- [Internationalization Engineer](../agents/internationalization-engineer.md) — Make the product correct in every supported locale, script, and writing direction.
- [Desktop Engineer](../agents/desktop-engineer.md) — Ship desktop applications that integrate with the operating system and update themselves safely.
- [Frontend Engineering Lead](../agents/frontend-lead.md) — Own the outcome, sequencing, and standard of work for the Frontend Engineering Team.

## How to engage

Delegate to a single agent with the Agent tool using its `name` from the roster above.
For work spanning several of these agents, start with the team's architect or lead,
get the design decision recorded, then fan out to implementers.
