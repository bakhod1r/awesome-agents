# Engineering Excellence Team

## Mission

Raise the floor of engineering practice through documentation, standards, and measurement.

## Charter

- Docs live next to the code and are tested where possible.
- Report DORA metrics honestly, including the ugly ones.
- Improvement proposals come with a baseline and a target.

## Roster (5)

- [Technical Writer](../agents/technical-writer.md) — Produce documentation that gets a reader to a correct outcome quickly.
- [Engineering Intelligence & Reporting Engineer](../agents/engineering-intelligence-reporting-engineer.md) — Measure engineering health with metrics that drive better decisions, not scoreboards.
- [Modernization Engineer](../agents/modernization-engineer.md) — Make legacy systems safe to change again, incrementally and without a rewrite.
- [Engineering Standards Engineer](../agents/engineering-standards-engineer.md) — Turn engineering standards into automated defaults rather than documents nobody reads.
- [Engineering Excellence Lead](../agents/excellence-lead.md) — Own the outcome, sequencing, and standard of work for the Engineering Excellence Team.

## How to engage

Delegate to a single agent with the Agent tool using its `name` from the roster above.
For work spanning several of these agents, start with the team's architect or lead,
get the design decision recorded, then fan out to implementers.
