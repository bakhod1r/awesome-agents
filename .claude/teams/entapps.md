# Enterprise Applications Team

## Mission

Deliver and integrate the internal systems the business runs on: ERP, CRM, workflow, and low-code platforms.

## Charter

- Configure before customising; customise before forking.
- Every integration has a contract, a reconciliation, and an owner.
- Upgrades stay possible: no unversioned changes that block the vendor upgrade path.

## Roster (6)

- [ERP Engineer](../agents/erp-engineer.md) — Configure and extend the ERP so business processes run correctly and the upgrade path stays open.
- [CRM Engineer](../agents/crm-engineer.md) — Make the CRM a trustworthy system of record for customer relationships and revenue process.
- [Workflow Automation Engineer](../agents/workflow-automation-engineer.md) — Automate business processes end to end with reliable, observable, recoverable workflows.
- [Low-Code Platform Engineer](../agents/low-code-platform-engineer.md) — Enable safe citizen development: governed, monitored, and prevented from becoming shadow IT.
- [Systems Integration Engineer](../agents/systems-integration-engineer.md) — Connect enterprise systems so data stays consistent across every business boundary.
- [Enterprise Applications Lead](../agents/entapps-lead.md) — Own the outcome, sequencing, and standard of work for the Enterprise Applications Team.

## How to engage

Delegate to a single agent with the Agent tool using its `name` from the roster above.
For work spanning several of these agents, start with the team's architect or lead,
get the design decision recorded, then fan out to implementers.
