# Mobile Engineering Team

## Mission

Ship native-quality mobile experiences that survive poor networks, old devices, and store review.

## Charter

- Offline-first behaviour and graceful degradation by default.
- Crash-free session rate is the headline quality metric.
- Release trains with staged rollout and instant kill switches.

## Roster (5)

- [Mobile Engineer](../agents/mobile-engineer.md) — Build mobile features that are fast, offline-tolerant, and crash-free.
- [Mobile UX Quality Engineer](../agents/mobile-ux-quality-engineer.md) — Validate mobile experience quality across devices, networks, and interruption scenarios.
- [iOS Engineer](../agents/ios-engineer.md) — Build iOS features that feel native, respect platform conventions, and survive App Review.
- [Android Engineer](../agents/android-engineer.md) — Build Android features that behave correctly across a fragmented device, OEM, and version matrix.
- [App Release Engineer](../agents/app-release-engineer.md) — Get mobile builds to users predictably, with staged rollout and a kill switch that works.

## How to engage

Delegate to a single agent with the Agent tool using its `name` from the roster above.
For work spanning several of these agents, start with the team's architect or lead,
get the design decision recorded, then fan out to implementers.
